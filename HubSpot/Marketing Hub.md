# 📚 HubSpot Marketing Hub — Full Summary

> Summary of 11 HubSpot Academy lessons covering the complete Marketing Hub toolset: Navigation, Contacts, Segmentation, Buyer Personas, Forms, CTAs, Email, Social Media, Workflows, Campaigns, and Reporting.

## 1️⃣ Introduction to Marketing Hub (#MarketingHub)

**Definition:** Marketing Hub is an **all-in-one marketing automation software** that helps marketers generate leads and automate marketing that drives growth.

### Three Core Objectives:
| Objective | Description |
|---|---|
| **Drive Revenue** | Attract, nurture, and convert high-quality leads |
| **Save Time & Resources** | Campaign management and automation tools in one place |
| **Measure & Optimize** | Reporting tools powered by CRM data |

### The Inbound Methodology in Marketing Hub:
| Stage | Tools |
|---|---|
| **Attract** | Ads, campaigns, social media, video |
| **Engage** | Forms, CTAs, email, automation |
| **Delight** | Live chat, SMS, WhatsApp, Meta Messenger, smart content, A/B testing |

### Key Features Along the Way:
- **Lead scoring**, behavioral events, segmentation, and reporting keep marketing data-driven and results-oriented.

### Integration with the HubSpot Ecosystem:
Marketing Hub works best alongside **Content Hub, Sales Hub, Service Hub, and Operations Hub**, all supported by the **Smart CRM**. The CRM serves as the single source of truth — storing contacts, companies, deals, tickets, and tasks — removing the need for complicated integrations and making cross-team collaboration seamless.

> 💡 Example: A contact created manually by sales or through a support ticket form appears in the shared CRM database, allowing the marketing team to engage using that stored information.

### Navigation Overview:
| Menu | Tools |
|---|---|
| **CRM → Contacts** | Contact records, interaction history |
| **CRM → Lists** | Hyper-targeted segments |
| **Marketing → Campaigns** | Plan, execute, track multi-channel campaigns |
| **Marketing → Marketing Email** | Personalized lead-nurturing emails |
| **Marketing → Social** | Manage/publish for Facebook, Instagram, X, LinkedIn |
| **Marketing → Ads** | Build/manage campaigns for Facebook, LinkedIn, Google |
| **Marketing → Forms** | Capture lead information |
| **Marketing → CTAs** | Engaging clickable buttons/banners |
| **Marketing → SMS** | Personalized text messages (add-on) |
| **Automations → Workflows** | Lead nurturing, drip campaigns, internal communications |
| **Reporting & Data → Reports** | Report collections, custom reports, dashboards |
| **Each tool → Analyze tab** | Channel-specific performance overview |

## 2️⃣ Exploring the Contacts Database in HubSpot (#ContactsDatabase)

**Definition:** The contacts database is the **foundation** where you create personalized experiences for contacts at scale. It's the center of all interactions and campaign tracking.

### What is Contact Management?
A strategy that uses software like HubSpot Marketing Hub to **source, store, and manage** a contact's information (name, contact history, email, etc.) stored in the HubSpot CRM.

### Three Key CRM Features:
| Feature | Description |
|---|---|
| **Contact Records** | Record and retrieve info on anyone your business interacts with; keeps everyone aligned |
| **Contact Properties** | Store specific info (email address, last form fill date); default properties are auto-populated (e.g., lifecycle stage) |
| **Lists** | Create lists of contacts/companies based on property values and activities for contextual nurturing |

### Two Important Steps When Using Your Database:
1. **Keep it clean and organized** — databases naturally decay yearly; evaluate quarterly; delete spam/ineligible contacts but consider future interaction potential first
2. **Customize the information you collect** — create custom contact, company, deal, ticket, and product properties

### How Information is Collected:
- **Automatic tracking:** page views, social media interactions, email marketing communications
- **Direct collection:** forms, chatbots, messaging apps, surveys
- **Integration & import:** sync other software systems directly with HubSpot

> ⚠️ A clean, customized database enables personalization at scale — helping you be human, helpful, and holistic in your inbound strategy.

### How to Access & Manage Contacts:
| Action | Navigation |
|---|---|
| View contacts | CRM → Contacts |
| View companies | CRM → Contacts dropdown → Companies |
| Manually create contact | CRM → Contacts → Create contact (Email*, First name*, Last name*) |
| Import contacts | CRM → Contacts → Import (CSV/XLSX/XLS or opt-out list) |
| Create custom properties | Settings → Data Management → Properties → Create property |
| View contact details | Click contact name → About section + Actions dropdown → Activities, Notes, Emails, Calls, Tasks, Meetings |

### Import Best Practices:
- Use CSV, XLSX, or XLS files
- Upload opt-out lists separately to maintain sending reputation
- Map columns to correct properties; choose "Create and update" to avoid duplicates
- Can create a contacts list from the import automatically

## 3️⃣ Understanding Segmentation in HubSpot (#Segmentation)

**Definition:** The process of separating customers into groups based on shared traits (personality, interests, habits) and factors (demographics, industry, income). **Segmentation brings together content and context.**

### Benefits of Segmentation:
- Learn about customers on a deeper level → tailor content to unique needs
- Create targeted campaigns and ads → resonate with and convert segments
- Improve customer service → prepare for challenges different groups face
- Increase customer loyalty → customized content and interactions
- Communicate via preferred channel/platform
- Identify new opportunities efficiently

### Types of Segments:
| Type | Description |
|---|---|
| **Lifecycle Stage** | Subscribers, leads, customers (tracked via lifecycle stage property) |
| **Buyer Persona** | Foundational segments based on ideal customer profiles |
| **Geographic** | Country, state, city, town |
| **Psychographic** | Personality, attitude, values, interests |
| **Technographic** | Mobile-use, desktop-use, apps, software |
| **Behavioral** | Tendencies, frequent actions, feature/product use, habits |
| **Needs-Based** | Product/service must-haves |
| **Value-Based** | Economic value of customer groups to the business |

### List Types in HubSpot:
| Type | Behavior | Best For |
|---|---|---|
| **Active Lists** | Dynamic — auto-update when contacts meet/stop meeting criteria | Ongoing email campaigns, lifecycle stage grouping, frequently changing properties (e.g., HubSpot score) |
| **Static Lists** | Fixed snapshot — don't change over time | One-time email blasts, event attendees, manual workflow enrollment, bulk deletion |

### Where to Use Segmentation:
- **Workflows:** List membership as enrollment trigger
- **Emails:** Select individual contacts or lists as recipients
- **Smart content:** Segment content delivery based on list membership

## 4️⃣ Using Buyer Personas in HubSpot (#BuyerPersonas)

**Definition:** A semi-fictional representation of your ideal customer based on real data and educated speculation about demographics, behavior patterns, motivations, and goals.

### Why Buyer Personas Matter:
- **"Knowing your audience is half the battle"** — no matter how clever your copy, if it doesn't resonate, it won't succeed
- Entire organization benefits: sales relates better, support solves problems faster
- Keeps the **customer at the heart** of the business
- Before any content creation, ask: **"Who is this for?"**

### Psychographic vs Demographic Data:
| Type | Description | Examples |
|---|---|---|
| **Psychographic** | Opinion-based — thoughts, opinions, aspirations | Goals, challenges, motivations |
| **Demographic** | Fact-based | Age range, income, education, location |

> 💡 Psychographic data may be *even more important* — it speaks directly to core motivations for doing business with you.

### Key Rules:
- Name personas memorably and alliteratively (e.g., "Skeptical Suzy", "Management Margaret")
- **Do NOT confuse buyer personas with job functions** — group by goal/challenge, not by title (sales manager vs sales director ≠ separate personas)
- Target **3–5 personas** max
- Treat personas as the **heroes of their own story**

### Research Questions:
| Category | Questions |
|---|---|
| **Goals (B2B)** | What does success mean in your role? |
| **Goals (B2C)** | What are your goals? |
| **Challenges** | What are your biggest pain points and frustrations? |
| **Role** | What do you do? Who do you report to? (not just title) |
| **Demographics** | Age, income, education, location |
| **Information Sources** | Which publications or blogs do you read? |

### How to Add Buyer Personas in HubSpot:
Settings → Data Management → Properties → Search "Persona" → Field type → **Add another persona**

Fields to fill:
- **Name** — memorable, alliterative
- **Description** — brief overview
- **Photo** — visualize the segment
- **Internal Notes:** Roles, Goals and Challenges
- **Demographics:** age, income, education, location
- **Short story** — dramatize: where they get info, free time, hopes and dreams

## 5️⃣ Creating Forms in HubSpot (#Forms)

**Definition:** Web forms embedded in your website to collect and manage visitor information efficiently — they're your **highest converting lead generation tool** (49.7% of marketers say so).

### Types of Web Forms:
| Type | Purpose |
|---|---|
| **Contact Forms** | Leads ask questions, voice concerns, request refunds |
| **Lead Generation Forms** | Convert visitors into leads (name, company, email, phone) |
| **Order Forms** | Place orders, payment, shipping/billing info |
| **Registration Forms** | Sign up for services |
| **Survey Forms** | Learn about customer experiences (multiple choice, fill-in-the-blank, long-form) |

### Form Design Best Practices:
| Practice | Detail |
|---|---|
| **Be simple and straightforward** | Imagescape increased conversions by 120% by reducing fields from 11 to 4 |
| **Use one column** | CXL Institute: 15.4 seconds faster completion vs multi-column |
| **Arrange easiest → hardest** | Start with name/email, then billing/shipping — commitment effect reduces abandonment |
| **Inline validation** | Real-time error checking for invalid emails, credit cards, etc. |
| **Positive error messages** | Never blame the user; use clear, concise language with direction |
| **Enable autofill/autocorrect** | Use browser-recognized field labels |
| **Summary boxes** | Address user concerns (e.g., explain why zip code is needed) |
| **Mobile experience** | Minimalist, color-coordinated, branded design |

### Form Examples:
- **Sun Bum "Ask the Bum"** — branded, personality-driven contact form
- **Starbucks Gift Card** — two-step form (intro → detailed order), single-column layout
- **Airbnb Registration** — exciting hosts with earnings potential ($2,622/month)

### How to Create a Form in HubSpot:
Marketing → Forms → Create form → **Embedded form** (part of website) or **Standalone page** (independent link)

Key Options:
- **Ticket Properties** — toggle to create tickets from submissions
- **Captcha** — enable/disable spam protection
- **Field settings** — required, hidden (pre-set values), progressive profiling (Pro/Ent), dependent fields (ask follow-up questions based on prior answers)
- **Follow-up options** — thank you message / redirect URL
- **Lifecycle stage** — customize submission lifecycle
- **Submission notifications** — notify contact owner or specific users
- **Campaign association** — Pro/Ent only
- **Always create contact** — new record for each unique email
- **Pre-populate fields** — known values from cookies (toggle on/off)
- **Reset form link** — "Not you? Click here to reset"

### Embedding Forms in Pop-Ups:
Marketing → CTAs → Create → Choose type:
| CTA Type | Behavior |
|---|---|
| **Sticky Banner** | Fixed top/bottom of page while scrolling |
| **Pop-Up Box** | Modal in middle of page |
| **Slide-In** | Emerges in corners, stays visible while scrolling |

Triggers:
- Page scroll percentage
- Exit intent
- Elapsed time (default 7 seconds)
- Inactivity duration

Targeting: specific pages, filtered visitors, frequency controls, mobile toggles, scheduling

## 6️⃣ Creating Calls-to-Actions in HubSpot (#CTAs)

**Definition:** An image or line of text that prompts visitors, leads, and customers to take action (download eBook, sign up for webinar, get coupon, attend event, etc.).

### Three Popular CTA Formats:
| Format | Description |
|---|---|
| **Image CTAs** | Banner ad with offer image + value text |
| **Button CTAs** | Clickable elements directing visitors to conversion pages |
| **Anchor Text CTAs** | Hyperlinked text within blog posts/pages |

### CTA Best Practices:
| Practice | Detail |
|---|---|
| **Actionable language** | Use second-person action verbs: "Download now", "Learn more", "Sign me up" — NOT "Submit" |
| **Length** | Keep between 90–150 characters |
| **Align with landing page** | Same offer name on CTA and landing page |
| **Clear value proposition** | Tell them exactly what happens when they click |
| **Urgency** | Use words like "now" or "today" |
| **High contrast design** | Should pop from the rest of the page |
| **Make it big** | No minimum standard — test what works |
| **Alt text** | SEO + accessibility for screen readers |
| **Prominent placement** | Above the fold = more clicks; below = higher quality leads |
| **A/B test** | Continuously tweak copy, design, sizing, placement |
| **Personalize** | Personalized CTAs perform **202% better** than basic CTAs (HubSpot study) |

### Smart CTAs (Pro/Ent):
Tailored to individual visitors based on:
- Location, browser language
- Whether they're already a customer, lead, or visitor
- Different audiences see different CTAs

### How to Create a CTA in HubSpot:
Marketing → CTAs → Create CTA

Options:
- **Button content** — text, button style, color picker
- **Image button** — upload image, adjust sizing and alt-text
- **Advanced options** — custom CSS, size adjustments
- **Redirect type** — External URL, HubSpot page/blog post, Meeting link
- **Open in new window** — toggle
- **Campaign association** — link to existing campaign

### Inserting CTAs into Content:
- **Rich text module** → toolbar → Insert → Call-to-Action → select and insert
- **CTA module** → select internal name of button → save

## 7️⃣ Getting Started With Email in HubSpot (#EmailMarketing)

**Why Email Marketing Matters:**
- **77%** of marketers saw a boost in email engagement (HubSpot 2023 stats)
- **50%** of recipients make purchases at least once monthly from email marketing
- **99%** of email users check their inbox daily
- More than promotional messages — it's about **building meaningful connections**

### Strategy Components:
Deliverability · Segmentation · Personalization · Automation

### Three Email Types in HubSpot:
| Type | Description | Availability |
|---|---|---|
| **Regular Email** | Personalized, one-time send to a specific segment | All plans |
| **Automated Email** | Configured to send when workflow criteria are met; reusable across workflows | All plans |
| **Blog/RSS Email** | Auto-sent to subscribers when new content publishes | Professional & Enterprise only |

### How to Create an Email:
Marketing → Email → Create email

Steps:
1. Choose email type
2. Select template (pre-made or HubSpot provided)
3. Think about purpose — what value will it provide?
4. Name the email (for organization)
5. Use drag-and-drop editor to edit/add components
6. For Blog/RSS: select blog, set frequency (instant/daily/weekly/monthly), choose display (summary or full post), set max number of posts

### Email Settings:
| Setting | Description |
|---|---|
| **From name** | Dropdown or dynamic token (contact owner) |
| **From address** | Dropdown or dynamic token |
| **Subject line** | Required; can use Breeze AI to generate |
| **Personalization tokens** | Contact, company, or custom tokens |
| **Preview text** | Shown in recipient's inbox |
| **Internal email name** | Visible only in HubSpot |
| **Language** | Dropdown selection |
| **Subscription type** | Required |
| **Campaign association** | Link email to a campaign |

### Email Performance Metrics:
Marketing → Email → Click email title → Performance page shows:
- Open rate, Click rate, Reply rate
- Delivery and Revenue Attribution
- Top clicked links
- Top engaged contacts
- Time spent viewing the email
- Engagement over time

## 8️⃣ Understanding Social Media in HubSpot (#SocialMedia)

### Why Social Media Matters:
1. **Expand marketing efforts** — increase chance content reaches the right audience
2. **Build brand awareness** — bring brand content directly to customers, partners, prospects
3. **Drive word-of-mouth** — Forbes: **71%** of consumers with good social media service experience recommend to others
4. **Attract buyers** — tie efforts into bigger marketing campaigns
5. **Communicate directly** — engaging with followers builds trust and loyalty

### HubSpot Social Capabilities:
- Schedule and publish content
- Monitor social feeds and watch competition
- Connect social efforts to broader campaigns
- Report on success

### Connecting Social Accounts:
Settings → Marketing → Social → Connect accounts

Supported networks: **Facebook (+Instagram)**, **X**, **LinkedIn**, **YouTube Reports**

Settings options:
- Default accounts toggle
- Publish now by default (immediate vs scheduled)
- Publish like a human (10-minute range vs exact time)
- Next post delay (time between multiple scheduled posts)
- Google Chrome extension (publish without going to HubSpot)
- Bitly integration (custom branded links)
- Blog auto-posting to social channels
- Team permissions (Enterprise admin: draft vs publish)

### Creating Social Posts:
Marketing → Social → Manage → Create social posts

Process:
1. Select accounts (dropdown)
2. Write message (emoji support via smiley icon)
3. Add link (paperclip → HubSpot content: blog post or landing page)
4. Generate with Copilot (Breeze Copilot for copy + hashtags)
5. Platform-specific editing (Instagram: Post/Reel/Story; YouTube: Title, Description, Video, Playlist, Tags, Language)
6. Publishing options: Publish now or Schedule for later
7. Add to marketing campaign (optional but recommended)

### Social Publishing Schedule:
Settings → Marketing → Social → Publishing tab

- Customize posting times per day of week
- Delete underperforming times
- Set default publishing (now vs schedule)
- Publish like a human toggle
- Next post delay per network
- HubSpot Social Media Chrome extension
- Alternative URL shortener connection

Viewing posts: Calendar view (drag-and-drop rescheduling) or List view (clone, delete, view on platform, create ad from Facebook posts)

AI Agent → Calendar events → View Suggestions → Regenerate (image/copy/hashtags)

### Social Reporting:
Marketing → Social → **Analyze tab**

Reports available:
| Report | What It Shows |
|---|---|
| **Audience** | Current followers (Facebook = page likes) |
| **Published Posts** | Number published in selected period (includes non-HubSpot posts) |
| **Interactions** | Likes, reactions, comments (excludes X retweets) |
| **Clicks** | Clicks on HubSpot-published posts only (uses shortened URLs) |
| **Shares** | Shared posts including X retweets (excludes LinkedIn personal, Instagram) |
| **Impressions** | Views on Facebook, Instagram, LinkedIn Company Pages |
| **Sessions** | Web sessions driven by social media |
| **New Contacts** | New contacts created from social-driven web sessions |
| **YouTube** | Watch time, views, interactions, subscribers gained/lost |

> ⚠️ Filter by: network, time period, campaign. Data based on publish dates. Posts connected to HubSpot pull in last 60 days automatically.

## 9️⃣ Understanding Workflows in HubSpot (#Workflows)

**Definition:** HubSpot's primary automation tool — software that automatically performs routine marketing tasks to scale without losing the human touch.

### Why Marketing Automation is Important:
| Use Case | Benefit |
|---|---|
| **Lead Nurturing** | Develop relationships over time; strategic journey design; responsive engagement |
| **Team Communication** | Internal notifications when leads qualify; improve visibility, accountability, reduce silos |
| **Data Hygiene** | Create specified segments; remove unengaged contacts; better deliverability |

> 💡 Example: Automated birthday discounts — personalized experience saved time, reduced human error, freed focus for other tasks.

### Creating a Workflow:
Automations → Workflows → Create workflow

**Two options:** From template (recommended — save time) or From scratch

**Workflow types:** Contact-based or Company-based (marketing); other options for sales/service

### Trigger Types:
| Type | When It Starts | Re-enrollment |
|---|---|---|
| **Event-based** | Specific action/event occurs (e.g., form filled) | Automatic every time trigger happens |
| **Filter-based** | Complex segmentation (e.g., area code + age > 30) | Must stop meeting criteria, then meet again |
| **Schedule-based** | Regular schedule (e.g., weekly Monday 8 AM) | Automatically re-enrolls when criteria met at scheduled time |

### Workflow Actions:
| Action | Description |
|---|---|
| **Send internal notification** | In-app, email, or marketing email to team members |
| **Send email** | Automated email from email editor |
| **Set marketing contact status** | Set as marketing/non-marketing contact |
| **Delay** | Calendar date, date property, event occurrence, set amount of time, specific days/times |
| **Branch** | Split paths based on logic |

### Branch Types:
- **One property or action output**
- **AND/OR logic** — multiple distinct branches
- **Random distribution by percentage**

### Workflow Goals:
Measures success of the workflow. Once contacts meet the goal, they're unenrolled. Only applies to workflows that send marketing emails.

Examples: List membership (MQLs), specific behaviors (webinar signup + page visit)

### Viewing Workflow Performance:
Automations → Workflows → **Analyze tab**:
- Total enrollments, running workflows, enrollment windows
- Percentage change of enrollments
- Visualizations and optimization opportunities

**Health tab:**
- Similar workflows (check for redundancies/conflicts)
- Workflows needing review
- Unused workflows

## 🔟 Creating a Campaign in HubSpot (#Campaigns)

**Definition:** A **connected series of operations** designed to bring about a particular result. Focused, acute marketing efforts with a singular goal.

### Marketing vs Advertising:
| | Marketing | Advertising |
|---|---|---|
| **Scope** | Broader — identify customer needs, define product, pricing, promotion | Paid media component of marketing |
| **Example** | Apple "Shot on iPhone" (product launch with Instagram, TV, photography collabs) | Nike sponsored Instagram post |

### Elements of a Successful Campaign:
| Element | Considerations |
|---|---|
| **Goals & KPIs** | Quantify end goal; measure in HubSpot, Google Analytics, Looker |
| **Channels** | Where are customers spending time? Prioritize best-performing |
| **Budget** | Agency, advertising, freelance costs → factor into ROI analysis |
| **Content Formats** | Multiple formats common (video ads, press releases, guest blogs) |
| **Team** | Copywriting, website building, design, budget planning, video |
| **Design Concept** | Own mission, vision, visual identity — consistent with parent brand but unique |
| **Deadlines** | Start date, end date, promotional calendar per channel |
| **Analysis** | Post-campaign measurement determines success |

### Key Metrics by Channel:
| Channel | Metrics |
|---|---|
| **Email** | Click-through rate, Bounce rate, Conversion rate |
| **Social (Paid)** | CTR, Conversion rate, Cost per click, Cost per conversion |
| **Social (Organic)** | Passive engagements, Active engagements, Follows, CTR |
| **Content Offers** | Opt-in rate, Cost per opt-in, Follow-up email open rate |
| **Display Ads/Paid Media** | CPC (cost per thousand), CTR, Conversion rate, Cost per conversion |
| **SEO** | CTR, Bounce rate, Time on page, Scroll depth, Conversion rate |

### How to Create a Campaign in HubSpot:
Marketing → Campaigns → Create campaign

Steps:
1. **Name** — representative and team-understandable (cannot be changed later)
2. **Description** — short description, approximate start date, budget, target personas, end date
3. **Edit goals** — visits, contacts, customers expected
4. **Associate assets:**
   - **Convert Contacts** — landing pages with forms
   - **Promote Campaign** — emails, blog posts, site pages, etc.
   - **Nurture Contacts** — workflows for further nurturing

### Campaign Reporting:
Two ways to report:
1. **Campaign tool itself** — metrics populate after assets linked (visits, contact growth, emails sent, CTA clicks)
2. **Analytics Suite → Campaign Analytics** — five metrics:

| Metric | Description |
|---|---|
| **Sessions** | Traffic to campaign-related assets |
| **New Contacts (first touch)** | Contacts attributed to campaign that brought them to site first time |
| **New Contacts (last touch)** | Contacts attributed to most directly contributing campaign |
| **Influenced Contacts** | New and existing contacts who engaged with campaign assets |
| **Closed Deals** | Closed won deals related to campaign-influenced contacts |
| **Influenced Revenue** | Closed revenue from campaign-influenced deals |

> 💡 Pro-tip: Create cohesive experience between landing pages, forms, and CTAs. Use HubSpot tasks for team organization. Use Marketing Calendar to visually document and track content creation.

## 1️⃣1️⃣ Understanding Reporting in Marketing Hub (#Reporting)

**Definition:** The process of gathering and analyzing marketing metrics to inform future decisions, strategies, and performance. Uncover meaningful, actionable data.

### Why Marketing Reporting Matters:
- Determine which channels work best
- Discover gaps in marketing strategy
- Advocate for more budget/headcount and allocate effectively
- Make effective decisions

### Three Starting Points:

#### 1. Traffic Reports
Reporting & Data → Reports → Traffic

Questions to answer:
- Trends over time? Spikes or dips?
- Which sources drive most traffic (organic, social, referrals, direct)?
- Which pages/content performing well or poorly?
- Geographical or demographic patterns?

#### 2. Analyze Tabs
Each marketing tool has an Analyze tab with channel-specific performance dashboards:
- Email → Analyze tab
- Social → Analyze tab
- Forms, CTAs, SMS → Analyze tabs
- Campaigns → Performance tab within each campaign

**Comparison feature:** Actions dropdown → Compare campaign (or Compare campaigns from all campaigns view)

#### 3. Custom Report Builder
Reporting & Data → Reports → Create report → Custom Report Builder

Steps:
1. Choose data source (Primary + optional Secondary)
2. Drag/drop axes: X-axis (e.g., Create Date), Y-axis (e.g., Count of Contacts), Break down by (e.g., Persona)
3. Add filters (timeframe, etc.)
4. Save to reports list or dashboard

> 💡 Pro tips: Review contacts-by-persona report monthly. Get familiar with the builder experience (axes, filters, data sources).

### Analytics Suite (Professional & Enterprise):
Reporting → Marketing Analytics

- **Quick answers** — prebuilt questions for fast insights
- **Chat with Chatspot** — AI assistant
- **All reports** — out-of-the-box marketing reports
- **Left sidebar topics** — Channel performance, Ads, Forms, Emails, SMS, Web traffic analysis
- **Filters** — Date range, Frequency, Group/break down, Compare with previous period
- **Save to dashboard** — custom naming, add to existing or new dashboard
- **Advanced reporting** (Enterprise) — customer journey analytics, attribution

### Attribution Reports:
Create report → Attribution

Configurable:
- **Chart type** — visualization style
- **Attribution model** — how credit is divided across interactions
- **Dimensions** — asset title, asset type, interaction source
- **Filters** — contact create date, asset types, campaigns

Run quarterly to understand broader business impact.

### Customer Journey Reports (Enterprise):
Create report → Customer Journey Reports

Uses **Sankey charts** — visualize flow/movement of data from one state to another.

Configure:
- Steps per stage (up to 5)
- Optional stages (first and last cannot be optional)
- Step-by-step conversion metrics table

> 💡 Build reports for all major conversion paths — even top performers may have improvement areas.
