# Create Records

## 🎯 Purpose
Creates one or more new records.

---

# 📦 Can Create

- Task
- Contact
- Opportunity
- Case
- Account
- Custom Objects

---

# ✅ Required

1. Select Object
2. Fill required fields

---

# 🧪 Example

```text
Object: Task
Subject: Call New Lead
Assigned To: Lead Owner
WhoId: Lead Id
```

---

# 📝 Notes

> **Create Records** always **INSERTS** a new record.
> It **never** updates existing records.
